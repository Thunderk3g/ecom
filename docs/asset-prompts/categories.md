# Category tile prompts — `public/images/categories/<slug>.png`

All tiles: **1:1 square, PNG, 1024×1024 minimum**. These are styled flat-lays/scenes that
represent the whole subcategory, not a single SKU — mirror the compositions of the
existing tiles (`notebooks.png`, `gifting.png`, etc.). Filename must match the category
slug exactly. Note: new slugs must also be added to `storefrontCategories` in
`src/utils/storefront-assets.ts` after the files land (post-generation step, see README).
Every block is self-contained. Style and batch rules: `style-guide.md`.
